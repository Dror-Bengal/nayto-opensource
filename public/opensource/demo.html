Marketing Analytics Dashboard

Code and setup ↓

Select City Desk to filter the dashboard by page. Expand a Weekend print workshop row to see which questions came up in the comments.

The demo uses 72 fictional posts across three pages. The read-only dataset and its benchmarks are dated November 26, 2026. Filters run in your browser. The comment analyses are prewritten.

Run locally

You’ll need Git and Docker with Compose. Run these commands in a terminal.

git clone https://github.com/Dror-Bengal/marketing-analytics-dashboard.git
cd marketing-analytics-dashboard
docker compose up --build -d

Once the build finishes, open localhost:18787. The sample data loads automatically. To stop the app and keep your data, run docker compose down.

Implementation tip

Compare posts within the same format. A reel has watch-time data that a photo cannot have. This dashboard uses a fixed 28-day window for its benchmarks, so changing the report dates keeps the comparison consistent.
